# 📊 Amazon Sales Exploratory Data Analysis (EDA)

This project performs an Exploratory Data Analysis (EDA) on an Amazon Sales dataset to uncover insights about product pricing, discounts, ratings, and category-wise trends using Python.

---

## 📌 Project Overview

The objective of this project is to:

- Clean and preprocess the dataset
- Explore product pricing and discount patterns
- Analyze customer ratings and rating counts
- Identify the most popular product categories
- Visualize important relationships between numerical variables
- Extract business insights from the data

---

## 📂 Dataset

The dataset contains Amazon product information including:

- Product Name
- Main Category
- Discounted Price
- Actual Price
- Discount Percentage
- Product Rating
- Rating Count

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Analysis Performed

### Data Cleaning

- Removed currency symbols from price columns
- Converted prices into numeric format
- Handled missing values
- Checked duplicate records
- Explored unique values

### Exploratory Data Analysis

- Distribution of prices
- Distribution of ratings
- Most popular product categories
- Relationship between actual and discounted prices
- Discount percentage analysis
- Rating vs Price
- Rating vs Discount Percentage

---

## 📊 Key Insights

- Most listed products are priced below ₹20,000.
- Product ratings are highly concentrated between **4.0 and 4.5**.
- Electronics dominate the dataset, followed by Computer Accessories and Home & Kitchen.
- Discounted prices have a strong positive relationship with original prices.
- Higher discounts do not necessarily correspond to higher customer ratings.
